# AQx–Tirole Omega v1.0

این بسته نمونه اولیه آموزشی برای غربالگری چندعاملی است. داده زنده بورس ایران در آن وجود ندارد و رتبه‌بندی واقعی نمادها تولید نمی‌کند.

## عوامل و وزن‌ها
- قدرت رقابتی: 25%
- جذابیت ارزش‌گذاری: 25%
- کیفیت سود: 15%
- ظرفیت رشد: 15%
- مومنتوم بازار: 10%
- کنترل ریسک: 10%

امتیازها باید بین صفر تا 100 باشند. اگر یکی از عوامل خالی باشد، امتیاز نهایی محاسبه نمی‌شود تا داده ناقص رتبه‌بندی کاذب نسازد.

## اجرا
نیازمند Python و کتابخانه‌های `pandas` و `numpy`:
```bash
pip install pandas numpy
python aqx_tirole_omega.py --input universe_input.csv --output aqx_ranked_output.csv
```
فایل `universe_input_template.csv` فقط قالب نمونه است؛ EXAMPLE_ONLY نماد واقعی نیست. فایل `iran_universe_blank.csv` فهرستی از نمادهای نمونه برای ورود داده دارد و امتیازهای آن عمداً خالی است.

## مونت‌کارلو
تابع `monte_carlo_terminal_values` سناریوهای فرضی بازده و نوسان را شبیه‌سازی می‌کند. تا وقتی پارامترها از داده معتبر و آزمون تاریخی کالیبره نشده‌اند، خروجی آن احتمال واقعی رشد یا زیان سهم نیست.

## محدودیت‌ها
- دریافت خودکار داده‌های بازار یا کدال پیاده‌سازی نشده است.
- ارزش‌گذاری بنیادی به داده‌های مالی معتبر و تاریخ‌دار نیاز دارد.
- افزایش سرمایه به‌تنهایی خلق ارزش نیست؛ محل افزایش سرمایه، رقیق‌شدن مالکیت و تغییر سودآوری باید جداگانه بررسی شود.
- امتیاز غربالگری سیگنال خرید/فروش یا تضمین بازده نیست.
